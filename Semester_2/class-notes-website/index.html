03
Reading guide

How to use these notes

These are revision notes, not a replacement for class. Used properly they cut a module down to about fifteen minutes of reading.

1

Read the big picture first. Thirty seconds, one analogy. If that paragraph does not make sense, the rest will not either — go back to the basics section above the concepts.

2

Work the examples with a pen. Every solved example has hidden steps written out with the reason next to them. Reading them silently feels productive and teaches nothing.

3

Read the trap box before the exam. The trap boxes collect the exact places where marks are lost: a base case, a sign, a particle, a unit.

4

Close the page and answer the practice questions. Answers are hidden behind each question. Mark the module as read only after you can answer the medium ones without looking.

5

Finish a subject against its syllabus. Every subject page links to the syllabus it was written from. Tick each sub-topic you can explain out loud — that is a better exam check than re-reading the notes.
