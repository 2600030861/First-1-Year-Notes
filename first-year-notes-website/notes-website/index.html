Reading guide

How to use these notes

These are revision notes, not a replacement for class. Used properly they cut a module down to about fifteen minutes of reading.

1

Read the overview first. It is the module in plain language, usually with the syllabus line for that module sitting at the top. If it does not make sense, the rest will not either.

2

Work the examples with a pen. Every worked example has its steps written out. Reading them silently feels productive and teaches nothing.

3

Use the tables as the revision layer. Most modules compress the examinable part into a comparison table or a definitions table — that is what you re-read the night before.

4

Close the page and answer the practice questions where a module has them. Mark the module as read only after you can answer the medium ones without looking.

5

Finish a subject against its syllabus. Every subject page links to the syllabus it was written from. Tick each sub-topic you can explain out loud — a better exam check than re-reading.
